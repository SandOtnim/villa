# คืนเดียวที่วิลล่า — ONE NIGHT AT THE VILLA

เกมภาพนิ่ง point-and-click เล่นได้ทั้งคนเดียวและเล่นพร้อมกันหลายคน

## เล่นออนไลน์
เปิดลิงก์ GitHub Pages ของ repo นี้ได้เลย

## เล่นกับเพื่อน
1. กด **เล่นกับเพื่อน** ที่เมนูหลัก
2. ใส่ชื่อ + รหัสห้อง แล้วกด **ก๊อปลิงก์ชวนเพื่อน**
3. ส่งลิงก์ให้เพื่อน — เพื่อนเปิดแล้วกด **เข้าห้อง** ได้เลย

ทุกคนจะเห็นเมาส์ของกันและกัน · ใครกดไปห้องไหน ทุกคนไปด้วยกัน
เชื่อมตรงระหว่างเครื่อง (WebRTC) ไม่มีเซิร์ฟเวอร์ ไม่ต้องสมัครอะไร

## ไฟล์
เกมทั้งเกมอยู่ใน `index.html` ไฟล์เดียว — ภาพโหลดจาก CDN
